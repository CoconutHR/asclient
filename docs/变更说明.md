# ASClient 变更说明

每个版本发布前更新本文档；历史细节可结合 `git log` 与对应标签查阅。

## 0.8.3（未发布）

### 新增

- YOLO 目标检测接口：`yolov_load(param, bin, yaml, use_gpu)` / `yolov_detect(target_size, threshold, nms_threshold, region/region_relative)` / `yolov_free()` / `yolov_nc()`，走设备端内置 ncnn 引擎（支持 YOLOv8/v11），推理在手机本地完成；检测结果自动附加载 yaml 的类别名，区域检测坐标自动加回偏移。需自备 ncnn 模型（ultralytics 训练转换），调用链已在 4001 真机验证（坏路径/未加载均优雅降级，完整推理需用户提供模型）。

## 0.8.2

### 新增

- 手势与点击扩展：`slide_path(points)` / `slide_path_relative(points)`（多段轨迹，逐段时长可配）、`touch_and_slide(...)` / `touch_and_slide_relative(...)`（按下/移动/抬起三段停留的拖拽）、`click_random(...)` / `click_random_relative(...)`（矩形内随机点击，坐标自动取整）、`tap`/`tap_relative`/`click_relative` 新增 `jitter` 参数（拟人随机抖动），CLI `tap`/`tap-rel` 新增 `--jitter`。
- 设备端视觉能力：`find_sift(templates)`（SIFT 特征匹配，抗尺度/光照变化，模板为设备端路径，支持 `region`/`region_relative` 与 `rgb`/`max_res`）、`scan_code()`（二维码/条码识别，返回值/类型/矩形）。两者均走设备端原生 OpenCV/MLKitx。
- 系统辅助：`screen_cache(enabled)`（设备端整帧缓存开关，批量找色/OCR 提速）、`notify(msg, title)`（系统通知）。全部在 iOS 4001 真机验证。

### 修复

- `click_random_relative` 的比例坐标经 `relative_point` 换算后为浮点，导致设备端 `randint` 报错；现由客户端取整。

## 0.8.1

### 新增

- 元素信息与滚动：`UiObject.get_text()`（设备端权威文本读取）、`UiObject.scroll(direction, distance)` 与 `UiObject.scroll_to(selector)`（可滚动元素内边滚边找，`UiCollection`/`SnapshotNode` 提供同名委托），底层走设备端 WDA 元素端点，真机验证通过。`clear_text` 经多方案真机验证（原生端点、HID 键、编辑菜单剪切模拟）后均不稳定，决定不提供；结论与替代建议记录在 API 参考。
- 设备信息与通知中心：`device_info()`（model/name/uuid/locale 等）、`battery_info()`（`{"level", "state"}`，整数枚举自动映射为 unplugged/charging/full/unknown）与 `open_notification()`（顶部下拉手势）；CLI 新增 `device-info` / `battery`（只读）与 `notification`（需要 `--yes`）。已记录设备端限制：`clear_text` 不可用——原生 WDA `/element/:id/clear`、聚焦后 clear、HID 删除键与退格符四种路径在该设备上均无效（真机确认），文档给出替代建议。
- App 与系统控制（对标 uiautomator2 的设备级 API，按现有命名风格实现）：`app_start()` / `app_stop()` / `app_state()`、`lock_screen()` / `unlock_screen()`、`get_clipboard()` / `set_clipboard()`、`orientation()`、`open_url()`、`dismiss_keyboard()`、`press_key()`（home/volume/power/snapshot），`Device` 提供同名委托；CLI 新增 `app-start` / `app-stop` / `app-state` / `lock` / `unlock` / `clipboard` / `orientation` / `openurl` / `key`。全部在 iOS 4001 真机验证。经专项复测确认的设备端限制：WDA `app_state` 状态码为完全静态值（前台/后台/被杀均返回相同码，客户端以同帧 `app_current` 修正，`background` 不可判定）；WDA `/wda/locked` 恒为 False（故不提供锁屏状态查询，文档给出截图全黑检测建议）；`/wda/apps/list` 出错（`app_list` 无法实现）；WDA `POST /orientation` 无实际效果（程序化旋转不可用，仅提供只读 `orientation()`）。根因均为设备端 wdapy 层吞错返回 None，客户端已按实锤行为文档化。
- 文件级重命名：`AScriptClient.rename_remote(path, new_name)`（同目录内改名，`new_name` 不能包含路径分隔符）与 CLI `py -m asclient mv 远程路径 新名字 --yes`；帮助覆盖 `py -m asclient help mv`。
- 单节点属性查询能力已在真机验证：选择器返回的元素携带 `id`（UUID），可直接作为设备端 `/api/node/attr` 的 `node_id` 使用，返回含 `scale`、`tag`、`accessible`、`displayed` 等树 dump 中没有的字段。

### 修复

- `status()` 在 iOS 4001 兼容降级时自动补偿：通过一次设备端 `eval` 回填等价的只读字段（`device`、`system` 含 `language`/`ios_version`/`timezone`、`app`、`python.version`），`compatibility.status_api.compensated_fields` 标注回填来源；`eval` 不可用时静默保持降级，不影响原有降级行为。服务端根因（`api_status.py` 第 49 行把 `languageCode` 属性当方法调用）与补偿边界已记录在[生产使用指南](生产使用指南.md)的"iOS 4001 status 兼容降级的根因与客户端补偿"。

### 改进

- 横屏坐标体系真机验证并补充文档：截图、OCR 文本矩形、图色区域、`tap`/`swipe` 在横屏（2556×1179）下与竖屏同样准确——按 OCR 矩形裁剪像素级对齐、点击桌面图标命中预期应用、滑动翻页成功；`action_size()`/`capture_frame()` 实时跟随设备方向，旋转后无需任何换算。支持矩阵与 README 坐标说明已同步。
- CI 矩阵覆盖 Python 3.12 与 3.13，与 `requires-python >= 3.10` 对齐。
- 补齐打包元数据：`pyproject.toml` 新增 `readme`、`authors`、`keywords`、`classifiers` 与项目 URL；`setup.py` 改为读取 `pyproject.toml` 的兼容壳（版本单一来源，发布时无需再单独同步）；新增 `asclient.__version__`。

## 0.8.0

### 新增

- `AScriptTunnel.from_config()`：从 `asclient.json` 的 `tunnel` 段创建 USB 隧道，显式参数优先于配置文件，与 CLI `tunnel` 命令共用同一份配置；过时别名 `executable` 发出 `DeprecationWarning`。
- `py -m asclient help <命令>` 覆盖全部 34 个命令的用法与参数说明（此前仅 8 个）。
- CLI 的 `--yes` 现在可写在子命令之后，与写在命令前等价，例如 `py -m asclient remove smoke --yes`。
- 完整可运行的带注释示例 [examples/完整流程示例.py](../examples/完整流程示例.py)。
- 视觉帧与取色 API：`ScreenFrame`、`PixelColor`、`capture_frame()`、`pixel()` / `pixel_relative()`、批量 `pixels()` / `pixels_relative()`；颜色默认以 `.rgb` 返回，也支持 `.hex`。
- 单帧视觉匹配：`find_images()`、`find_any_image()`、`wait_any_image()`；多模板共享同一截图，每个模板均可指定物理像素 `region` 或比例 `region_relative`。`region_pixels` 是弃用别名；旧比例 `region` 调用应迁移到 `region_relative`。
- 显式本地 UI 快照：`device.snapshot()` 和 `UiCollection.snapshot()`，支持本地 `.child()`、`.descendant()`、`.parent()`、`.sibling()` 关系查询，无需向设备端发送未知关系 selector。
- 完整树查询优先使用设备端 `config.scale` 校验 Retina 坐标换算。
- 元素等待支持可配置 `interval`，新增单树轮询的 `device.wait_any()`；快照集合新增本地 `.where_regex()` 正则筛选。
- 坐标 API 统一为“无后缀=物理像素绝对坐标、`*_relative`=比例坐标”；补齐 `Device` 的绝对动作/裁剪门面、`Selector.at_relative()`、元素内部 `click_relative()`、全图像 API 的 `region_pixels`，以及快照的点查询和全字段倒排索引。
- 高频交互与断言：新增长按、双击、拖拽、前台 App 等待、锁内 `click_if_unique()`、结构化 OCR（含真机物理像素文本矩形）及颜色三表达/区域断言 API。Python 动作的 `duration` 使用秒；`duration_ms` 保留兼容。CLI 旧 `--duration` 继续使用毫秒，并新增 `--duration-ms` / `--duration-s`。
- 查询提速与滚动找控件：坐标空间按 `coordinate_cache_ttl`（默认 1 秒）短时缓存，元素等待从每轮 3 次设备往返降到 1 次；`ui_tree`/`find_elements`/`find_all`/`.exists`/`.count` 支持跳过坐标归一化；新增 `scroll_until_element()`（滚动直到语义控件出现）与 `device.watch()` 后台规则监控（弹窗自动处理，支持自定义动作与触发上限）。
- 文档全面改版：文件名改为中文；README 新增“最短上手”与“任务速查”；教程补齐 doctor/status/首个程序/Inspector 的真实期望输出、Inspector 界面布局图、“完整流程示例”与“等待与超时模型”章节；`serve()` 补充 `output_dir` 参数文档。

### 改进

- `Run` 证据文件名保留中文等 Unicode 步骤名：中文步骤名现在直接生成如 `填写用户名_failure.png` 的文件名，不再退化为 `step_*`（`manifest.json` 始终保留原始名称；`/`、`\`、`:` 等文件名非法字符仍替换为下划线）。
- `doctor` 在 `device.address` 为非回环地址（Wi-Fi）时，缺失 `iproxy` 由 `error` 降级为 `warning`，不再导致退出码 `1`；回环地址（USB 场景）仍为 `error`。

### 修复

- 中文系统上两个单元测试因断言英文文案而失败；测试现在固定英文输出，不再依赖操作系统语言。
- 修正多处文档与实际行为不符：`screen_size()` 返回值形态、USB 隧道启动输出样例、`dump_hierarchy()` 语义、排错表中不存在的 `available: false` 状态、`AScriptTunnel` 直接构造与 `from_config` 的字段名差异等。
